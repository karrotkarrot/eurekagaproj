🔄 End-to-End Data Flow Pipeline
1

representation.py

Models backbone length ($DP$) and sorted side-branches (`PEBranch`). Assembles SMILES and converts to SELFIES string.

Class: PERepresentation, PEBranch | SELFIES Dual Encoding
2

ga_generator.py

Executes single-point crossover & token mutation directly on SELFIES representations to guarantee 100% syntactically valid offspring graph structures.

Class: PEGAGenerator | Tournament Selection & Elitism
3

validator.py

Sanitizes molecular graph via RDKit valence laws and canonicalizes SMILES strings to eliminate duplicate structural representations.

Class: PEValidator | Chem.SanitizeMol & Canonical Cache
4

fitness.py

Computes Molecular Weight ($M_n$), tertiary carbon SMARTS matches `[CH1]([#6])([#6])[#6]`, degradation risk index, and composite fitness.

Class: PEFitnessEvaluator | Thermal Degradation Proxy
5

visualizer.py & main.py

Generates summary Pandas DataFrame, exports results to CSV, and draws 2D molecular grid images via RDKit `Draw.MolsToGridImage`.

Class: PEVisualizer | CSV & PNG Deliverables
💡 Scientific & Engineering Rationale

1. Why SELFIES + SMILES Dual Representation?
Standard SMILES strings are fragile: mutating a single character (like a parenthesis) almost always causes an invalid SMILES syntax error. SELFIES (Self-Referencing Embedded Strings) guarantees that 100% of mutated string vectors correspond to valid molecular graphs.

2. What is Thermal Degradation Risk Index?
Tertiary carbon sites ($\text{-CH}(R_1)(R_2)\text{-}$) at branch connection points have lower C-H bond dissociation energies ($\sim 390\text{ kJ/mol}$) compared to secondary $\text{-CH}_2\text{-}$ backbone carbons ($\sim 410\text{ kJ/mol}$). During plastic melting, tertiary carbons act as weak links susceptible to thermal chain scission. Minimizing tertiary branch density retains material integrity.

3. Fallback Safety Guarantee
All modules contain pure-Python fallback handlers (`try...except ImportError`). If RDKit or SELFIES are absent in a lightweight environment, the system automatically switches to mathematical formula mass approximations and regex validation without crashing.

🖨️ 3D Printing Melt Extrusion Compatibility Profile

Optimized candidate PE structures are evaluated for downstream Fused Deposition Modeling (FDM) 3D printer filament extrusion. Controlling the melting point ($T_m$) and degradation index ensures smooth nozzle flow without polymer thermal degradation.

Python API Usage Example
from codebase.PE.representation import PERepresentation, PEBranch
from codebase.PE.fitness import PEFitnessEvaluator

# 1. Instantiate polyethylene structure
pe = PERepresentation(dp=12, branches=[PEBranch(position=4, length=1)])
smiles = pe.to_smiles()

# 2. Evaluate thermal degradation risk & fitness
evaluator = PEFitnessEvaluator(target_mn=1000.0)
props = evaluator.evaluate_properties(smiles)
print(f"Fitness: {props['fitness_score']:.4f} | Mn: {props['mn']:.1f}")
