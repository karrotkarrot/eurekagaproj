# eureka-ga (Polyethylene GA Optimization)

Polyethylene (PE) Genetic Algorithm (GA) Optimization System for designing monomer structures to minimize thermal degradation during plastic melting while optimizing Number Average Molecular Weight ($M_n$).

## Structure

- [`codebase/PE`](codebase/PE/): Core Python package including representation, GA generator, chemical validator, fitness calculation, visualizer, and tests.
  - See [`codebase/PE/README.md`](codebase/PE/README.md) for full architecture and scientific documentation.

## Quick Start

```bash
cd codebase/PE
pip install -r requirements.txt
python main.py
```
